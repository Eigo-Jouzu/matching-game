# Matching Game

This is a basic word matching game designed for Japanese students learning English as a second language.

The program is designed to run in a web browser on students' iPads.

The functionality is currently limited to parsing a single hard-coded JSON file, populating cards with phrases from the JSON file, and pronouncing the words with speech synthesis.

In the future, this is intended to use many different JSON files for a variety of word lists.

The [qrcodejs](https://github.com/davidshimjs/qrcodejs) library included in this project uses the MIT license.
